## 現在のネットワーク構成

今回のハッカソン環境は、セキュリティを担保するためにデータベース（RDS）が外部インターネットから遮断された「VPC（仮想プライベートクラウド）内部」に配置されています。

そのため、外部と通信できるEC2サーバーを「踏み台（中継地点）」として利用する、実務でも非常によく使われるセキュアな構成になっています。

- **手元のMac (VS Code / ブラウザ)**
    - `localhost:8000` にアクセスすると、VS Codeの「ポートフォワーディング機能」により、SSHの暗号化通信を通ってEC2の8000番ポートへリクエストが転送されます。
- **EC2サーバー (Ubuntu / パブリックIP: 57.182.155.197)**
    - VPC内に配置された開発用サーバーです。
    - ここでFastAPI（Uvicorn）が起動しており、Macからのリクエストを受け取ります。
- **RDS (PostgreSQL / プライベートIP)**
    - VPCのさらに奥（インターネットからアクセスできない場所）にあります。
    - 同じVPC内にいるEC2サーバーのFastAPIアプリケーションからのみ、5432番ポート経由で安全に接続されます。

## ここまで実施した対応内容のまとめ

### 1. EC2へのセキュアな接続の確立

- 共有されたテキスト形式の秘密鍵から `.pem` ファイルを作成し、アクセス権限（`chmod 400`）を適切に設定しました。
- VS Codeの「Remote - SSH」拡張機能を設定し、Mac上のVS CodeからEC2サーバーへ直接接続して透過的に開発できる環境を構築しました。

### 2. サーバー内の開発環境セットアップ

- ツール管理マネージャーの `mise` を導入しました。
- `mise` を経由して、プロジェクトの指定バージョンである **Python 3.13** と、高速なパッケージマネージャーである **uv** をグローバルにインストールしました。

### 3. FastAPIプロジェクトの設定最適化

- **DB接続設定の柔軟化:** 過去のDocker前提のコード（`src/core/config.py`）を改修し、`.env` ファイルから `DB_HOST` と `DB_PORT` を動的に読み込んでRDSへ接続できるように修正しました。
- **ビルド設定の調整:** `uv` がアプリケーションコードをライブラリとして誤検知・ビルドしようとするのを防ぐため、`pyproject.toml` に `[tool.uv] package = false` を追記しました。
